================================
CONFIGURACIÓN DE SUPABASE
================================

Ahora usamos:
✅ Supabase PostgreSQL - Para la base de datos
✅ Firebase Authentication - Para autenticación

================================
PASO 1: CREAR PROYECTO EN SUPABASE
================================

1. Ve a https://supabase.com/
2. Click en "Start your project"
3. Crea una cuenta o inicia sesión
4. Click en "New Project"
5. Completa:
   - Name: hackathon_gamificacion
   - Database Password: (Guarda esta contraseña, la necesitarás)
   - Region: South America (sao-paulo) o la más cercana
   - Pricing Plan: Free (suficiente para empezar)
6. Click "Create new project"
7. Espera 2-3 minutos mientras se crea el proyecto

================================
PASO 2: OBTENER CREDENCIALES
================================

Una vez creado el proyecto, ve a:
Settings (⚙️) > Database

Encontrarás:

1. Connection String:
   postgresql://postgres.[REFERENCIA]:[PASSWORD]@[HOST]:5432/postgres

2. Connection Info:
   Host: db.[REFERENCIA].supabase.co
   Database name: postgres
   Port: 5432
   User: postgres
   Password: [LA QUE CONFIGURASTE]

3. Connection pooling (opcional, para mejor rendimiento):
   postgresql://postgres.[REFERENCIA]:[PASSWORD]@[HOST]:6543/postgres?pgbouncer=true

================================
PASO 3: CONFIGURAR VARIABLES DE ENTORNO
================================

Crea/actualiza tu archivo .env en backend/:

# ============ SUPABASE ============
# Opción 1: Connection String (RECOMENDADO)
DATABASE_URL=postgresql://postgres.[REFERENCIA]:[PASSWORD]@db.[REFERENCIA].supabase.co:5432/postgres

# Opción 2: Credenciales individuales
DB_HOST=db.[REFERENCIA].supabase.co
DB_PORT=5432
DB_NAME=postgres
DB_USER=postgres
DB_PASSWORD=tu_password_de_supabase

# API de Supabase (opcional, si quieres usar el cliente de Supabase)
SUPABASE_URL=https://[REFERENCIA].supabase.co
SUPABASE_ANON_KEY=tu_anon_key
SUPABASE_SERVICE_KEY=tu_service_role_key

# ============ FIREBASE AUTH ============
FIREBASE_SERVICE_ACCOUNT_PATH=./config/serviceAccountKey.json

# ============ SERVIDOR ============
PORT=3000
NODE_ENV=development

================================
PASO 4: EJECUTAR SCHEMA EN SUPABASE
================================

Tienes 3 opciones:

--- OPCIÓN A: SQL Editor en Supabase (MÁS FÁCIL) ---

1. Ve a SQL Editor en Supabase
2. Click en "New query"
3. Copia y pega el contenido de backend/config/schema.sql
4. Click "Run" (▶️)
5. Repite con backend/config/init_data.sql

--- OPCIÓN B: psql desde tu terminal ---

psql "postgresql://postgres.[REFERENCIA]:[PASSWORD]@db.[REFERENCIA].supabase.co:5432/postgres" -f config/schema.sql

--- OPCIÓN C: TablePlus / DBeaver ---

1. Descarga TablePlus o DBeaver
2. Crea nueva conexión PostgreSQL
3. Usa las credenciales de Supabase
4. Ejecuta los archivos SQL

================================
PASO 5: VERIFICAR TABLAS CREADAS
================================

En Supabase:
1. Ve a Table Editor
2. Deberías ver las tablas:
   - personas
   - roles
   - credenciales
   - medicos
   - especialidades
   - medico_especialidad
   - documentos
   - citas

================================
PASO 6: INSTALAR DEPENDENCIAS Y EJECUTAR
================================

cd backend
npm install
npm run dev

================================
PASO 7: VERIFICAR CONEXIÓN
================================

Visita: http://localhost:3000/test-connection

Deberías ver:
{
  "success": true,
  "database": {
    "status": "Conectado a Supabase PostgreSQL",
    "serverTime": "...",
    "version": "PostgreSQL ..."
  },
  "firebase": {
    "status": "Firebase Auth inicializado",
    "projectId": "tu-proyecto-firebase"
  }
}

================================
MIGRACIÓN DE FIREBASE DATA CONNECT
================================

Si tenías datos en Firebase Data Connect:

1. Exporta datos desde Cloud SQL:
   pg_dump -h IP_CLOUD_SQL -U postgres -d database > backup.sql

2. Importa a Supabase:
   psql "postgresql://postgres...@supabase.co:5432/postgres" -f backup.sql

================================
SOLUCIÓN DE PROBLEMAS
================================

Error: "password authentication failed"
→ Verifica que usaste la contraseña correcta de Supabase
→ La contraseña es la que configuraste al crear el proyecto

Error: "no pg_hba.conf entry for host"
→ Verifica que incluyas SSL en la conexión
→ Revisa que dataconnect.js tenga ssl: { rejectUnauthorized: false }

Error: "connect ETIMEDOUT"
→ Verifica tu conexión a internet
→ Verifica que el DATABASE_URL sea correcto

Error: "database does not exist"
→ En Supabase siempre usa database: postgres
→ No cambies el nombre de la base de datos
