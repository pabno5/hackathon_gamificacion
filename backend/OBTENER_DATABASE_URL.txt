================================
CÓMO OBTENER DATABASE_URL DE SUPABASE
================================

Si tienes SUPABASE_URL y SUPABASE_KEY pero te falta DATABASE_URL,
sigue estos pasos:

================================
PASO 1: IR A CONFIGURACIÓN
================================

1. Ve a https://app.supabase.com/
2. Selecciona tu proyecto
3. Click en el ícono de ⚙️ Settings en la barra lateral izquierda
4. En el menú de Settings, click en "Database"

================================
PASO 2: ENCONTRAR CONNECTION STRING
================================

Desplázate hacia abajo hasta encontrar la sección:
"Connection string"

Verás varias pestañas:
- URI
- Session mode
- Transaction mode

✅ SELECCIONA LA PESTAÑA "URI" (la primera)

================================
PASO 3: COPIAR LA CONNECTION STRING
================================

Verás algo como esto:

postgresql://postgres.abcdefghijk:[YOUR-PASSWORD]@aws-0-us-east-1.pooler.supabase.com:5432/postgres

⚠️ IMPORTANTE: 
Esta string tiene [YOUR-PASSWORD] como placeholder.
Necesitas reemplazarlo con tu contraseña real.

================================
PASO 4: OBTENER TU CONTRASEÑA
================================

La contraseña de tu base de datos es la que configuraste cuando
creaste el proyecto en Supabase.

Si NO LA RECUERDAS:
1. En la misma página (Database settings)
2. Busca la sección "Database password"
3. Click en "Reset database password"
4. Copia la nueva contraseña
5. Click en "Apply" para confirmar

⚠️ ADVERTENCIA: 
Resetear la contraseña desconectará todas las aplicaciones
que estén usando la contraseña anterior.

================================
PASO 5: CONSTRUIR TU DATABASE_URL
================================

Toma la connection string y reemplaza [YOUR-PASSWORD]:

ANTES:
postgresql://postgres.abcdefghijk:[YOUR-PASSWORD]@aws-0-us-east-1.pooler.supabase.com:5432/postgres

DESPUÉS (con tu contraseña real):
postgresql://postgres.abcdefghijk:MiPasswordReal123!@aws-0-us-east-1.pooler.supabase.com:5432/postgres

================================
PASO 6: AGREGAR A TU .env
================================

Crea o edita el archivo backend/.env y agrega:

DATABASE_URL=postgresql://postgres.abcdefghijk:TuPasswordReal@aws-0-us-east-1.pooler.supabase.com:5432/postgres

================================
EJEMPLO COMPLETO DE .env
================================

# Supabase Database (REQUERIDO para PostgreSQL)
DATABASE_URL=postgresql://postgres.abcdefghijk:MiPassword123@aws-0-us-east-1.pooler.supabase.com:5432/postgres

# Supabase API (opcional, no se usa para SQL)
SUPABASE_URL=https://abcdefghijk.supabase.co
SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

# Firebase Auth
FIREBASE_SERVICE_ACCOUNT_PATH=./config/serviceAccountKey.json

# Servidor
PORT=3000
NODE_ENV=development

================================
DIFERENCIAS IMPORTANTES
================================

❌ SUPABASE_URL
   - Es para la API REST de Supabase
   - Formato: https://xxx.supabase.co
   - NO sirve para conectarse a PostgreSQL

✅ DATABASE_URL
   - Es para conectarse directamente a PostgreSQL
   - Formato: postgresql://user:password@host:port/database
   - ES LO QUE NECESITAS para este proyecto

================================
VERIFICAR QUE FUNCIONA
================================

Una vez agregado DATABASE_URL a tu .env:

1. Reinicia el servidor:
   npm run dev

2. Deberías ver en consola:
   🔌 Usando DATABASE_URL de Supabase
   ✅ Conectado a Supabase PostgreSQL

3. Visita:
   http://localhost:3000/test-connection

4. Deberías ver:
   {
     "success": true,
     "database": {
       "status": "Conectado a Supabase PostgreSQL",
       ...
     }
   }

================================
SOLUCIÓN DE PROBLEMAS
================================

Error: "password authentication failed"
→ Verifica que reemplazaste [YOUR-PASSWORD] correctamente
→ Asegúrate de no tener espacios al copiar/pegar

Error: "connect ETIMEDOUT"
→ Verifica tu conexión a internet
→ Verifica que la URL sea correcta

Error: "no pg_hba.conf entry"
→ Asegúrate de usar el puerto 5432 (no 6543)
→ Usa el modo "URI" no "Session mode"

Error: "database does not exist"
→ Asegúrate de que el database sea "postgres" al final
→ No cambies el nombre de la base de datos

================================
ALTERNATIVA: CREDENCIALES INDIVIDUALES
================================

Si prefieres NO usar una connection string, puedes usar
credenciales separadas:

En Supabase Dashboard > Settings > Database, encontrarás:

Host: aws-0-us-east-1.pooler.supabase.com
Database: postgres
Port: 5432
User: postgres.abcdefghijk
Password: [tu contraseña]

Agrégalas a tu .env así:

SUPABASE_DB_HOST=aws-0-us-east-1.pooler.supabase.com
SUPABASE_DB_PORT=5432
SUPABASE_DB_NAME=postgres
SUPABASE_DB_USER=postgres.abcdefghijk
SUPABASE_DB_PASSWORD=tu_password_aqui

El código las detectará automáticamente si no hay DATABASE_URL.

================================
¿NECESITAS AYUDA?
================================

Si sigues teniendo problemas:

1. Verifica que tu proyecto de Supabase esté activo
2. Asegúrate de que el plan free no haya expirado
3. Revisa que copiaste la contraseña correcta
4. Intenta resetear la contraseña y volver a intentar
5. Comparte el error específico (sin tu contraseña)
