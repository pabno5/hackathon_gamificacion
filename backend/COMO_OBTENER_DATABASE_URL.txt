================================
OBTENER DATABASE_URL DE SUPABASE
================================

PASOS:

1. Ve a https://app.supabase.com/
2. Selecciona tu proyecto
3. Click en Settings (⚙️) en la barra lateral
4. Click en "Database"
5. Scroll hasta "Connection string"
6. Selecciona la pestaña "URI"
7. Copia el string que se ve así:

postgresql://postgres.xxxxx:[YOUR-PASSWORD]@aws-0-us-east-1.pooler.supabase.com:5432/postgres

8. Reemplaza [YOUR-PASSWORD] con tu contraseña real

9. Agrégalo a tu .env como:

DATABASE_URL=postgresql://postgres.xxxxx:tu_password@aws-0-us-east-1.pooler.supabase.com:5432/postgres

================================
IMPORTANTE:
================================

SUPABASE_URL (https://xxx.supabase.co) 
→ Es para la API REST, NO para PostgreSQL

DATABASE_URL (postgresql://...) 
→ Es para conectarse directamente a PostgreSQL
→ ES LA QUE NECESITAS
